If you see this page, the server is running.

An HTTP/1.1 server built from scratch in C — no libraries, no framework. Single-threaded, event-driven architecture built on a kqueue/epoll abstraction, handling raw request parsing, zero-copy static file serving via sendfile(), and CGI script execution. Written for macOS and Linux using POSIX APIs and compiled with clang.

HTTP/1.1 GET · HEAD · OPTIONS · POST Event-driven (kqueue / epoll) Zero-copy static file serving CGI support Keep-Alive connection FSM request parser Configurable via include/core/config.h
Architecture 
src/
├── core/
│   ├── event/  ← kqueue / epoll abstraction
│   ├── reactor.c ← main event loop
│   └── main.c    ← entry point
├── http/       ← parser, router, handler, responder
├── net/        ← sockets & sendfile() abstraction
├── ds/         ← generic data structures (ring buffer, ...)
└── utils/      ← misc tools

include/        ← headers (mirrors src/)
└── core/config.h ← port, backlog, request limits
